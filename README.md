# Kcraftify Art Studio 🎨

A premium, mobile-first portfolio website for a resin art brand built with modern frontend technologies and a strong focus on performance, UI/UX, and conversion.

---

## ✨ Overview

Kcraftify Art Studio is a handcrafted resin art brand based in Gujarat, India.  
This website showcases curated collections like coasters, wall art, and jewelry with a luxury design approach and a seamless inquiry-based experience.

The goal is to provide a visually rich, fast, and conversion-focused platform where users can explore designs and directly connect via WhatsApp for custom orders.

---

## 🚀 Tech Stack

- ReactJS (TypeScript + Hooks)
- Tailwind CSS (mobile-first design)
- Framer Motion (smooth animations)
- Firebase Hosting (deployment)
- Firestore (optional inquiry storage)

---

## 💎 Features

- 🎥 Cinematic hero section with optimized video background
- 🖼️ Interactive gallery with category filters
- 🔍 Fullscreen lightbox preview for products
- ⭐ Testimonials with dynamic star ratings and auto-scroll
- 📱 Mobile-first responsive design
- 💬 WhatsApp integration for instant product inquiries
- 🎨 Premium dark UI with gold accents and glassmorphism
- ⚡ Performance optimized (lazy loading, compressed media)
- 🔎 SEO-ready structure (meta tags, sitemap, semantic HTML)

---

## 🎯 Key Highlights

- Designed for **high mobile engagement (India-focused audience)**
- Built with **conversion-first UX (inquiry-based, no checkout)**
- Carefully crafted to maintain a **luxury brand feel**
- Optimized for **fast loading and smooth interactions**
